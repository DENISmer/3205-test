# 3205-test

A fullstack application for url tests

## Структура проекта

- `web/` — фронтенд (Vite + React + TS)
- `api/` — бэкенд (NestJS + TS)

## Запуск

Требуется Node.js и Yarn.

```bash
yarn install   # поставить зависимости
yarn dev       # поднять одновременно бек и фронт
```

Другие команды из корня:

```bash
yarn lint      # линт api + web
yarn format    # форматирование api + web
```
